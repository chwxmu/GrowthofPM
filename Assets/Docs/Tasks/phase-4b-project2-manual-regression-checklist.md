# P2 手工回归清单（Phase 4B 收口与演示加固）

## 适用范围

- 本清单用于 `P2：Phase 4B 收口与演示加固` 的 Unity 编辑器内人工回归。
- 本次重点覆盖：P2 关键 UI 静态化效果、Week 3 / 5 / 9 / 11 / 12 主流程、继续游戏恢复、小游戏重进、三档演示路径。
- 不覆盖 `P3` 正式内容、Phase 6 音频/设置/全局 polish、大范围框架重写。

## 回归前准备

- [ ] 从 `Assets/Scenes/MenuScene.unity` 进入 Play，不要直接在 `GameScene` 裸启动正式回归。
- [ ] 开始新用例前，确认旧存档是否需要删除，避免沿用错误上下文。
- [ ] 在 Hierarchy 中锁定运行时 `GameManager` Inspector，便于观察 `currentProject`、`currentWeek`、`hiddenRisk`、`savedFlowStage`。
- [ ] 如需快速验证分支，可在非首轮复跑时结合已有测试或调试入口缩短准备时间，但正式演示路径至少保留一轮完整流程。

## A. 静态 UI 与布局烟雾

- [ ] `DecisionPanel`：标题/说明/AI建议按钮行/反馈区/固定关闭按钮都存在于场景层级中，显示不依赖首次运行时新建。
- [ ] `CPMGamePanel`：标题/说明/状态文本/反馈区/底部固定按钮容器存在于场景层级中。
- [ ] `RiskDashboardPanel`：标题/说明/计时文本/结果区/固定关闭按钮存在于场景层级中。
- [ ] 关键静态 TMP 文本与按钮标签使用 `Assets/Fonts/SIMSUN SDF.asset`。
- [ ] 缩小窗口后，不出现按钮遮挡、说明文本严重截断、反馈文案压住选项区的问题。

## B. Week 3：CPM 小游戏

- [ ] 进入 Week 3 后，主流程进入 `CPMGamePanel`，而不是跳过小游戏。
- [ ] 连接正确顺序后点击“确认”，显示成功反馈，并能继续回到周流程。
- [ ] 故意连错后点击“确认”，显示失败反馈，并能继续回到周流程。
- [ ] 点击“重置”后，当前依赖关系清空，不残留旧连线。
- [ ] 关闭结果后再次进入 Week 3 / 重新开始 P2，不会残留旧反馈或旧连线。

## C. Week 5：条件事件

- [ ] 当 `cpmCorrect = true` 时，Week 5 不触发“逻辑阻塞”惩罚对白。
- [ ] 当 `cpmCorrect = false` 时，Week 5 触发额外对白、属性惩罚与风险惩罚。
- [ ] 条件事件结束后能稳定进入日程，不出现流程悬挂。
- [ ] 在条件事件对白中退出并“继续游戏”，能回到正确上下文，不重复扣除惩罚。

## D. Week 9：Risk Dashboard 小游戏

- [ ] 进入 Week 9 后，主流程进入 `RiskDashboardPanel`。
- [ ] 红色模块可点击修复，绿色模块误点会给出错误反馈。
- [ ] 倒计时自然结束后，会显示“修复/遗漏/误点”统计结果。
- [ ] 关闭结果后返回周流程，不出现交互锁或空白面板。
- [ ] 再次进入 Week 9 / 重新开始 P2 时，不残留上一局统计文案或按钮状态。

## E. Week 11：风险对白

- [ ] `hiddenRisk < 30` 时命中低风险对白。
- [ ] `30 <= hiddenRisk < riskFailThreshold` 时命中中风险对白。
- [ ] `hiddenRisk >= riskFailThreshold` 时命中高风险对白。
- [ ] 在风险对白阶段退出并“继续游戏”，能回到正确上下文，不跳回周初。

## F. Week 12：结局与转场

- [ ] `excellent` 路径：低风险 + 高属性时命中“电商教父”。
- [ ] `pass` 路径：风险未爆表但不满足优秀条件时命中“修补匠”。
- [ ] `fail` 路径：高风险优先命中“背锅侠”，不会被高属性覆盖。
- [ ] `fail` 结局没有“继续下一个项目”入口。
- [ ] `pass / excellent` 结局先进入 P2 -> P3 转场，再由“开始新项目”进入 P3。

## G. 保存 / 继续游戏恢复

- [ ] 在 Week 3 小游戏入口前保存并继续，恢复到正确周与正确面板。
- [ ] 在 Week 3 / Week 9 小游戏阶段保存并继续，至少恢复到小游戏入口面板。
- [ ] 在 Week 5 条件事件后保存并继续，不重复应用惩罚。
- [ ] 在 Week 11 风险对白后保存并继续，恢复到正确周内阶段。
- [ ] 在 Week 12 结局页或转场页保存并继续，能回到对应结局/转场，不回退到周初。

## H. 演示路径复现

- [ ] `excellent` 路线：谨慎决策 + 小游戏发挥稳定，风险维持低位。
- [ ] `pass` 路线：出现少量错误或中风险，但不触发失败阈值。
- [ ] `fail` 路线：错误决策 + 小游戏失误，稳定推高风险并命中失败。
