# P1 手工回归清单

## 适用范围

- 本清单用于 `P1：Phase 3 收口验收` 的 Unity 编辑器内人工完整点击回归。
- 本次回归重点覆盖：P1 九周流程、Week 3 双决策、P1 三档结局、失败结局阻断进入 P2、成功/合格进入 P2 转场、继续游戏后的关键周内阶段恢复。
- 本清单不覆盖 P2 小游戏、P3 正式内容、音频、美术大改、设置系统或主循环重写验证。

## 回归前准备

- [x] 从 `Assets/Scenes/MenuScene.unity` 开始，不要直接从 `Assets/Scenes/GameScene.unity` 开始。
- [ ] 进入 Play 后，在 Hierarchy 中找到运行时生成的 `GameManager`，锁定 Inspector，便于观察 `_currentPlayerData`。
- [ ] 第一次完整烟雾回归不要按 `P`；后续定向复跑可用 `P` 跳过本周主剧情以加速。
- [ ] 开始新用例前，确认当前存档状态符合目标；必要时先删除旧存档再执行。

## A. P1 九周完整烟雾

- [x] 从菜单点击“新游戏”，进入 Project 1 Week 1。
- [x] Week 1：剧情可正常播放，决策面板有 3 个选项，选完后可进入日程。
- [x] Week 2：无决策，剧情结束后可直接进入日程。
- [x] Week 3：完成后可继续推进到 Week 4，不出现卡死、跳周或重复结算。
- [x] Week 4 ~ Week 8：都能按“剧情 / 决策 / 日程 / 结算”正常推进。
- [x] Week 9：完成日程后可稳定进入结局页，不报错、不黑屏。
- [x] 整个 P1 能从 Week 1 跑到 Week 9，中途 `currentProject` 始终为 `1`，周数逐周递增。

## B. Week 3 双决策专项

- [x] 重新开档或读取到 Week 3。
- [x] 完成第一个决策后，关闭反馈。
- [x] 预期立刻进入第二个决策，不会直接跳到日程。
- [x] 第二个决策完成后，才进入日程安排。
- [x] Week 3 两次决策的属性变化都能正常反映到顶部状态栏。
- [x] Week 3 完整结束后，周数从 `3` 正常推进到 `4`。

## C. Week 3 继续游戏恢复

- [x] 在 Week 3 第一个决策完成、第二个决策已经弹出时，退出 Play。
- [x] 回到 `MenuScene` 后再次进入 Play，点击“继续游戏”。
- [x] 预期直接恢复到 Week 3 第二个决策，不回到 Week 3 开头。
- [x] 预期不会重复获得第一个决策已经结算过的属性收益。
- [x] 完成第二个决策后，可正常进入日程并完成本周。

## D. P1 三档结局验证

- [x] 在 Week 9 日程确认前，查看 `GameManager._currentPlayerData` 当前四维。
- [x] `fail` 用例：将四维临时修改为低值，例如 `10 / 10 / 10 / 10`，然后完成 Week 9。
- [x] 预期出现“失败之路”，且没有“继续下一个项目”按钮。
- [x] `pass` 用例：将四维修改为满足及格阈值但不满足卓越阈值，例如 `90 / 90 / 90 / 90`，然后完成 Week 9。
- [x] 预期出现“合格之路”，且有“继续下一个项目”按钮。
- [x] `excellent` 用例：将四维修改为满足卓越阈值，例如 `140 / 140 / 140 / 140`，然后完成 Week 9。
- [x] 预期出现“卓越之路”，且有“继续下一个项目”按钮。

## E. 失败结局阻断验证

- [x] 在 `fail` 结局页确认看不到“继续下一个项目”。
- [x] 只应保留“重新开始”和“返回主菜单”相关操作。
- [x] 无论如何点击现有按钮，都不会错误进入 P2。
- [x] 返回主菜单后，“继续游戏”不会把玩家带进 P2 转场或 P2 Week 1。

## F. 成功 / 合格进入 P2 转场验证

- [x] 在 `pass` 或 `excellent` 结局页点击“继续下一个项目”。
- [x] 预期先出现 P1 -> P2 转场页，而不是直接进入 P2 正文。
- [x] 此时查看 `GameManager._currentPlayerData.currentProject`，预期仍为 `1`。
- [x] 此时查看 `GameManager._currentPlayerData.pendingProjectNumber`，预期为 `2`。
- [x] 点击“开始新项目”后，才真正进入 P2。
- [x] 进入 P2 后检查：`currentProject = 2`、`currentWeek = 1`、`energy = 300`、`hiddenRisk = 0`。

## G. 转场页继续游戏恢复

- [x] 在 P1 结局页点击“继续下一个项目”，进入转场页后先不要点击“开始新项目”。
- [x] 直接退出 Play。
- [x] 回到 `MenuScene` 后再次进入 Play，点击“继续游戏”。
- [x] 预期直接恢复到 P1 -> P2 转场页。
- [x] 预期不会回到 Week 9 开头，也不会直接跳进 P2 Week 1。
- [x] 在恢复后的转场页点击“开始新项目”，P2 仍应正常启动。

## H. 结局页继续游戏恢复

- [x] 在 Week 9 结局页出现后，不点击任何按钮，直接退出 Play。
- [x] 回到 `MenuScene` 后再次进入 Play，点击“继续游戏”。
- [x] 预期直接恢复到当前结局页。
- [x] 预期不会重跑 Week 9，也不会重复结算日程和属性变化。
