## 研究数据口径说明摘要

### 可直接引用的结论

1. **查看率**：以玩家是否主动点击“查看AI建议”为准。
2. **采纳率**：以玩家选择是否与 AI 推荐选项一致为准。
3. **项目采纳率**：按 `projectNumber` 聚合，适合用于 `P1 / P2 / P3` 对比。
4. **P3 质量拆分**：按 `aiQuality` 在 `P3` 范围内统计 `good / neutral / bad` 的采纳率。
5. **决策耗时**：以 `decisionLatencyMs` 保存到 `save.json`，适合论文离线统计，不强制进运行时 UI。
