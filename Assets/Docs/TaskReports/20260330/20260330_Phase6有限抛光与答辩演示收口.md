## 本轮实现内容

### 1. 对白推进快捷键收口

- `DialoguePanel` 新增了键盘推进支持：当对白面板处于显示状态时，玩家现在可以使用 `Space`、主键盘 `Enter`、小键盘 `Enter` 推进对白。
- 对白提示文案同步更新为“点击 / 空格 / 回车继续”，让答辩演示时的操作提示更清晰。
- `ShowDialogues()` 现在会显式调用 `EnsureLayout()`，避免某些非标准创建路径下布局未初始化导致的空引用或提示文本缺失。

### 2. 主菜单“继续游戏”禁用态提示补齐

- `MenuSceneController` 在刷新继续游戏按钮时，除了设置 `interactable`，还会同步更新按钮文案：
  - 有存档：`继续游戏`
  - 无存档：`继续游戏（无存档）`
- 兼容 `TMP_Text` 与旧 `UnityEngine.UI.Text` 两种标签获取方式，避免场景资源细节差异导致失效。

### 3. 调试快捷键降风险

- `StoryManager` 中原本可直接通过 `P` 跳过本周主剧情的调试快捷键，改为仅在 `Unity Editor` 下通过 `Shift + P` 触发。
- 这样保留了开发调试效率，同时降低答辩演示时误触跳剧情的风险。

### 4. 最小自动化护栏补充

- 在 `QuizScheduleVisibilityTests` 中补充了 4 个与本轮收口直接对应的 EditMode 用例：
  - 对白提示文案是否包含快捷键说明
  - 快捷推进是否能进入下一句对白
  - 无存档时继续游戏按钮是否禁用并显示说明
  - 有存档时继续游戏按钮是否恢复默认文案并可用
