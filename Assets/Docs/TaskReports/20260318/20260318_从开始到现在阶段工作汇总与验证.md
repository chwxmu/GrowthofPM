## 核心逻辑
1. 上传范围控制
- 按需求调整 `.gitignore`，上传时不包含 `Assets/Docs/` 目录内容。

2. 流程 7-12 自动化测试落地
- 新增 `Phase2Flow7To12Tests`，覆盖：
  - 日程安排（精力扣减/回收、超额防护、确认回调）；
  - 可选答题（答题奖励与反馈）；
  - 周结算与保存；
  - 周推进与项目结局；
  - 项目过渡展示。
- 同步修复 `QuizPanel` 反馈区组件冲突问题，避免运行态空引用。

3. 决策事件 UI 与流程修复
- 为每个选项展示效果预览（如“技术力 +2”），锁定选项展示锁定原因。
- 选择选项后不再自动关闭，改为显示“关闭”按钮，由玩家确认后关闭并继续流程。
- 关闭按钮统一改为右上角锚点按钮（`EnsureCornerButton`）。
- 无 AI 建议时隐藏 AI 建议文本区域，不再残留“暂无AI建议”干扰文案。
- 补充并修复中文文本（技术力/沟通力/管理力/抗压力）与相关编码问题。

4. 日程安排 UI 重构
- 左侧 `Task Library` 改为可滚动任务库（`ScrollRect` + `Viewport` + `Content`）。
- 右侧 `Weekly Plan` 改为可滚动已选任务列表。
- 底部 `Footer` 固定确认按钮在右下区域。
- 新增/统一关闭按钮并放置在右上角。
- 日程项动态 TMP 文本统一设置为 `SIMSUN SDF`。

5. 顶部状态栏入口与布局优化
- 新增“日程安排”入口按钮，并放置在“答题”按钮左侧。
- 原 `+` 入口文案改为“答题”。
- 上移精力行相关 UI（标签/数值/滑条）以优化遮挡和间距。

6. 顶部按钮点击无响应问题修复
- `TopStatusBar` 中入口按钮不再通过 `button.interactable=false` 硬禁用，而改为保留点击并由阶段判定给出反馈日志。
- `StoryManager` 新增/完善：
  - `CanOpenQuiz()` / `CanOpenSchedule()`
  - `OpenQuizFromSchedule()` / `OpenScheduleFromTopBar()`
  - `CloseQuizAndReturn()`
- `GameScene` 中 `PanelsRoot` 的遮罩图形关闭 `Raycast Target`，避免上层透明节点吞掉点击事件。

7. 答题面板交互统一
- 答题界面新增右上角关闭按钮。
- 移除旧“返回日程安排”路径，关闭后回到流程控制器（`StoryManager.CloseQuizAndReturn()`）。
- 答题页面文字与按钮标签字体统一为 `SIMSUN SDF`。
