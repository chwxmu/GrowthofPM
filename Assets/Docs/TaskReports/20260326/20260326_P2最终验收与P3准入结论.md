## 本次发现并修复的问题

### 1. P2 合格结局描述存在字体缺字风险

- 在新增的 P2 终验用例中，`EndingPanel` 渲染 `p2_pass` 结局描述时出现了 `SIMSUN SDF` 缺字警告：字符 `宕`（U+5B95）无法在指定字体资源中正确显示。
- 这类问题会直接影响答辩展示观感，属于 Phase 4C 范围内必须处理的“文本严重显示问题”。
- 处理方式：将 `Assets/Resources/Data/endings.json` 中 `p2_pass` 的描述文案由“系统宕机约20分钟”调整为“系统停机约20分钟”，保留原语义，不改结局逻辑。

### 2. P2 终验缺少“演示路径与小游戏重进”级别的自动化护栏

- 原有基线已覆盖 P2 主流程闭环，但对以下答辩展示级问题仍缺少专门保护：
  - `CPMGamePanel` / `RiskDashboardPanel` 重新进入时的状态重置
  - `excellent / pass / fail` 三条 P2 演示路径是否可稳定命中对应风险档位与结局
  - `pass` 结局进入转场、`fail` 结局阻断下一项目、P2 -> P3 时隐藏风险归零
- 本次补充了最小必要的 EditMode 用例，保证这些“最终验收”关注点后续不会回退。
