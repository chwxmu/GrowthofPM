## 关键面板视觉升级说明

### 1. `MenuScene`

- 将主菜单背景接入夜景办公室图，替换原纯色背景为更完整的办公夜景氛围。
- 在主菜单右下角加入 `朱诀` 立绘作为主视觉人物，强化“项目经理成长记”的主角识别度。
- 对主按钮统一应用蓝灰系颜色主题，并为“新游戏 / 继续游戏”加入图标前缀，提升层级感与展示完成度。

### 2. `TopStatusBar`

- 为四维属性与精力行补齐图标，改善状态栏原先“只有文字与滑条”的程序感。
- 为答题与日程入口按钮加入功能图标，并补充底部强调线，增强顶部状态区的整体完成度。

### 3. `DialoguePanel`

- 新增基于角色名的立绘映射，常见剧情角色进入对白时可自动显示对应立绘。
- 新增办公日景/夜景的语义背景回退逻辑，在首批背景资源不足时优先覆盖高频办公场景。
- 调整对白底板、背景遮罩、文本颜色与布局：文本区收敛到左下，立绘区独立放置在右侧，可读性明显优于原纯色版本。

### 4. `DecisionPanel`

- 为面板加入标题图标、淡化浮水印、AI 建议区图标和选项提示行，强化“决策事件”与“查看 AI 建议”的视觉主次。
- 选项按钮新增左侧图标，按钮风格保持统一蓝灰系，同时保留现有锁定态与反馈逻辑。

### 5. `TransitionPanel`

- 加入顶部进度主题图标、右上低透明装饰图标和带图标的“开始新项目”按钮。
- 内容底板强化描边和层次，让项目切换页更像正式章节过渡页。

### 6. `EndingPanel`

- 加入顶部经验主题图标、按钮图标、面板描边和低透明度装饰图，弱化纯色弹窗感。
- 保留结局信息与 AI 采纳率的原有逻辑，不影响结局跳转安全性。

### 7. `GameSummaryPanel`

- 顶部增加总结主题图标和装饰图，强化最终总结页的展示感。
- 为四维属性条、项目采纳率条、质量条补齐图标，提升统计信息的可扫读性。
- 为底部“重新开始 / 返回主菜单”按钮增加图标前缀，统一与其它面板的交互风格。

## 核心逻辑实现说明

### 1. 统一运行时资源访问

- 新增 `UIVisualResources.cs` 作为轻量资源访问层，负责缓存 `Resources` 下的背景、角色立绘和图标。
- 同时在其中维护角色名到立绘资源名的映射，以及对白地点的办公场景语义回退规则。

### 2. 不改剧情数据契约，直接增强现有 UI

- 没有修改 `DialogueLine`、`DecisionEventData` 等 JSON/C# 数据契约。
- 角色立绘与背景切换均在 `DialoguePanel` 内根据现有 `speaker` / `location` 自动解析，避免影响现有剧情数据与测试基线。

### 3. 静态页与动态页分别低风险升级

- `MenuScene`、`TopStatusBar` 采用“已有控件 + 最小必要运行时装饰”的方式升级。
- `DialoguePanel`、`DecisionPanel`、`TransitionPanel`、`EndingPanel`、`GameSummaryPanel` 则沿用原有 `EnsureLayout()` 动态构建模式，在现有布局基础上补视觉元素。
