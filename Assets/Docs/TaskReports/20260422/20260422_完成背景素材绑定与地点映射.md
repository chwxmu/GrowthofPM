# 背景素材绑定与地点映射任务报告

## 任务背景

本次任务仅处理背景类素材绑定，不接入 `Assets/images1/background/` 下的按钮、面板、标题框等 UI 皮肤资源。

- `MenuScene` 只替换静态大背景 `BackgroundPanel`
- `GameScene` 只替换常驻玩法背景 `GameplayBackground`
- 对话背景统一通过 `DialoguePanel._locationBackgrounds` 的 Inspector 序列化映射处理
- 不修改 `DialoguePanel.cs`、`UIVisualResources.cs` 等运行时代码

- `Assets/Scenes/GameScene.unity`

1. `MenuScene`

- 将 `BackgroundPanel` 的 `Image.sprite` 替换为 `Assets/Material/主界面图片.jpg`
- 保持 `HeroIllustration` 继续引用 `Assets/Resources/UI/Characters/zhu_jue.png`
- 未接入 `游戏logo.png`、按钮底图、标题框等 UI 皮肤素材

- 未修改 `TopStatusBar`、面板壳层、按钮和标题区的静态资源
