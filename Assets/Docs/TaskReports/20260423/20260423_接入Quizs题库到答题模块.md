# 接入 Quizs 题库到答题模块任务报告

## 任务背景

你在 `Assets/Resources/Quizs` 新导入了 PMBOK 相关题目（5 个模块 txt 文件），需要配置到现有答题模块中使用。

现有运行时逻辑固定读取 `Assets/Resources/Data/quiz_questions.json`，因此本次采取离线合并方式：保留旧题、追加新题并全局去重，不改答题运行时入口。

## 修改文件

- `Assets/Scripts/Editor/QuizQuestionImportTool.cs`
- `Assets/Resources/Data/quiz_questions.json`
- `Assets/Docs/TaskReports/20260423/20260423_接入Quizs题库到答题模块.md`

## 核心逻辑

1. 新增离线导入工具

- 新增 Editor 工具脚本 `QuizQuestionImportTool`，用于把 `Quizs/*.txt` 转换并合并到 `quiz_questions.json`。
- 题型映射规则：
  - `技术力模块题目.txt` -> `techPower`
  - `管理力模块题目.txt` -> `managePower`
  - `抗压力模块题目.txt` -> `stressPower`
  - `PMBOK管理知识题目.txt` -> `random`
  - `沟通力模块题目.txt` -> `commPower`
- 在“全局去重”前提下，导入优先级将 PMBOK 放在沟通力之前，确保重合题优先进入 `random` 池。

2. 文本解析与清洗

- 解析格式：`题干:A选项:B选项:C选项:D选项:答案序号(1-4)`。
- 处理项：
  - 去题号前缀（如 `1.` / `1、`）
  - 兼容全角字符（如 `Ｄ`、全角空格、全角标点）
  - 压缩多余空白字符
- 只接收有效题目：题干非空、4 个选项齐全、答案在 1-4 区间。

3. 合并与去重

- 以仓库中原有 `quiz_questions.json` 为基底（保留旧题）。
- 新题按“题干 + 4 选项”归一化键去重，避免重复出题。
- `questionType` 保留映射结果，最终仍由现有 `QuizPanel` 逻辑按题型抽题。

- 本次保持运行时读取路径不变，答题模块仍从 `Data/quiz_questions.json` 加载题目。
