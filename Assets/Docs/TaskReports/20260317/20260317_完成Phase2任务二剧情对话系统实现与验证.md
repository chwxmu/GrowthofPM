# 任务报告：完成 Phase2 Task 2 剧情对话系统实现与验证

## 任务背景
根据 `Assets/Docs/Tasks/phase-2-core-gameplay.md` 的 Task 2 要求，完善 `DialoguePanel`，实现剧情对话展示、打字机效果、点击推进、说话人刷新、地点驱动背景切换以及完成回调，确保可接入每周主流程。

## 修改文件
- `Assets/Scripts/UI/DialoguePanel.cs`

## 核心逻辑
- 对话入口：实现 `ShowDialogues(List<DialogueLine> dialogues, Action onComplete)`，支持空数据快速结束并回调。
- 打字机播放：保持约 30 字/秒逐字显示；点击时若正在打字则立即补全当前句，否则推进到下一句。
- 角色与文本刷新：每条 `DialogueLine` 切换时刷新 `speaker` 与 `text`，并提供旁白兜底文案。
- 地点背景切换：新增 `UpdateBackgroundByLocation/ResolveBackgroundSprite`，支持
  - Inspector 映射（`locationKeyword -> Sprite`）
  - `Resources` 路径回退查找（`Backgrounds/Dialogue`、`Backgrounds/Locations`、`Backgrounds`）
  - 未命中时使用默认背景并输出一次性日志
- UI 自动构建：`Awake()->EnsureLayout()` 自动补齐背景层、文本区、点击区域，避免场景字段为空导致不可运行。
- 字体规范：动态创建的 TMP 文本统一通过 `SIMSUN SDF` 优先解析，符合中文字体规范。

## 当前游戏完整流程
1. 进入流程
   - 从 `MenuScene` 开始新游戏/继续游戏，或在 `GameScene` 直进 Play 时由 `GameManager` 自动引导启动主流程。
2. 周循环开始
   - `StoryManager.StartWeek()` 读取当前周数据，刷新顶部状态栏，进入周流程状态机。
3. 周初剧情（Prologue）
   - 通过 `DialoguePanel.ShowDialogues(...)` 播放周初对话；项目 3 在此后会进入 DailyIntro。
4. 日常导入剧情（DailyIntro，仅项目 3）
   - 继续使用 `DialoguePanel` 播放日常导入小故事，然后进入决策阶段。
5. 决策事件（Decision）
   - `DecisionPanel` 展示事件描述、AI 建议、选项按钮。
   - 选项支持“按选项级属性条件锁定”；玩家选择后应用属性变化与风险变化。
   - 同步记录实验埋点：`hasViewed`、`isFollowed`、`decisionLatencyMs`。
   - 若该周存在双决策或条件事件，则按周数据继续串行处理。
6. 决策后剧情（PostDecision，可选）
   - 若周数据配置了决策后对话，则先播放后再进入日程安排。
7. 日程安排（Schedule）
   - `SchedulePanel` 进行精力分配与任务选择；顶部栏答题入口在该阶段可用。
8. 可选答题（Quiz，可选）
   - 从顶部栏进入 `QuizPanel`；答题结束可返回日程面板继续安排。
9. 周结算（Settlement）
   - 确认日程后结算任务属性、固定周属性、风险自动变化；立即保存进度。
10. 推进下一周
   - 若未到当前项目最后一周：周数 +1，重置周精力，重新进入下一周剧情。
11. 项目结局（Ending）
   - 到达项目末周后计算结局（含项目 2 隐藏风险阈值），显示 `EndingPanel`。
12. 项目过渡（Transition）
   - 若存在下一项目，可继续到 `TransitionPanel`，继承属性并开启新项目周循环；否则停留最终结局。
