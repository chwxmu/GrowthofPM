# 任务报告：完善结局与过渡面板显示与布局

## 任务背景
在项目一第 9 周完成日程安排后，游戏未能正确表现出结局阶段与项目切换阶段的 UI 反馈，玩家会误以为流程卡死。同时，结局界面与新项目过渡界面在长文本场景下存在排版问题：结局文案会发生重叠，过渡界面的“继承属性”区域会被“开始新项目”按钮遮挡。本次任务对结局阶段显示链路、调试日志与过渡界面布局进行统一修复，并补充自动化回归测试。

## 修改文件
- `Assets/Scripts/Managers/StoryManager.cs`
- `Assets/Scripts/UI/EndingPanel.cs`
- `Assets/Scripts/UI/TransitionPanel.cs`
- `Assets/Tests/Editor/Phase2Flow7To12Tests.cs`

## 核心逻辑
1. 结局与项目切换流程修复
- 在 `StoryManager` 中补充最终周结算、项目结束、继续到下一项目等关键节点日志。
- 确保项目最后一周完成日程后进入 `Ending` 状态，并在点击继续后进入 `Transition` 状态。

2. 结局界面显示修复
- 为 `EndingPanel` 增加可见性恢复逻辑，避免面板在被隐藏后重新显示时仍保持透明或不可交互。
- 将长结局文案改为更稳定的详情布局，并在显示时主动刷新文本高度，避免描述、属性和 AI 采纳率互相重叠。

3. 过渡面板显示与布局修复
- 此前已修复 `TransitionPanel` 的可见性恢复问题，保证从结局进入新项目时面板可以正常显示和点击。
- 本次进一步调整 `TransitionPanel` 的布局结构，取消滚动内容方案，改为“标题 + 描述 + 继承属性 + 弹性留白 + 底部固定按钮”的直接展示布局。
- 通过动态计算文本高度和底部留白，将“开始新项目”按钮稳定压到面板底部，避免遮挡继承属性内容。

## 测试结果
1. EditMode 自动化测试
- 运行 Unity EditMode 全量测试，结果为 `30 passed, 0 failed, 0 skipped`。

2. 覆盖的关键验证点
- 验证最终周完成日程后可进入结局面板，并恢复可见与可交互状态。
- 验证点击继续后可正常进入项目过渡面板。
- 验证结局界面长文案不会与统计信息重叠。
- 验证过渡界面的继承属性文本位于按钮上方，按钮固定在最下方且不遮挡内容。
