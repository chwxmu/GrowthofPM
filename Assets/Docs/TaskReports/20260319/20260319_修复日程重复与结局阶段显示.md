# 任务报告：修复日程重复与结局阶段显示

## 任务背景
本次任务主要处理两个影响核心周流程体验的问题：一是日程安排界面的任务库条目重复出现；二是项目一最后一周完成日程后未正常显示结局与项目切换界面，同时结局界面长文本排版发生重叠。

## 修改文件
- `Assets/Scripts/UI/SchedulePanel.cs`
- `Assets/Scripts/Managers/StoryManager.cs`
- `Assets/Scripts/UI/EndingPanel.cs`
- `Assets/Scripts/UI/TransitionPanel.cs`
- `Assets/Tests/Editor/Phase2Flow7To12Tests.cs`

## 核心逻辑
1. 日程重复问题修复
- 为 `SchedulePanel` 增加动态列表缓存同步逻辑，在布局缓存丢失后优先重新绑定已有任务节点，避免重复创建按钮导致同一任务显示多份。

2. 结局阶段流程修复
- 在 `StoryManager` 的最后一周结算、周推进、项目结束与进入下一项目流程中补充调试日志。
- 确保项目最后一周完成日程后能够正确进入 `Ending` 状态，并在点击继续后进入 `Transition` 状态。

3. 结局界面排版修复
- 为 `EndingPanel` 增加文本布局刷新逻辑，并将结局详情区域改为可滚动内容区。
- 长结局描述、属性面板和 AI 采纳率信息会按内容高度自动排版，避免文本互相重叠。

## 测试结果
1. EditMode 自动化测试
- 运行 Unity EditMode 测试，结果为 `29 passed, 0 failed, 0 skipped`。

2. 新增/覆盖验证点
- 验证日程面板重复打开后任务库不再重复渲染。
- 验证最终周完成日程后结局面板会恢复可见与可交互状态。
- 验证继续下一个项目后过渡面板可见性恢复正常。
- 验证长结局描述会进入滚动区域，不再与其他文本重叠。
